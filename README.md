## Featured work

### Portfolio — a full-stack product

A bilingual portfolio with a custom admin area, MongoDB-backed content, contact forms, and an end-to-end meeting booking flow.

- **Live:** [artemlira.com](https://artemlira.com)
- **Frontend:** [React-Portfolio_multipage](https://github.com/artemlira/React-Portfolio_multipage) · React 19, Vite, Redux Toolkit, React Router, i18next, SCSS Modules
- **Backend:** [MERN_Portfolio-back](https://github.com/artemlira/MERN_Portfolio-back) · Node.js, Express, MongoDB Atlas, Mongoose, JWT

The owner can manage projects, skills, facts, contacts, and social links through protected pages on the website. Visitors can send a message or book a meeting. The API checks availability, creates a Google Calendar event and Google Meet link, stores the booking, and emails the visitor and owner. GitHub Actions runs the projects' configured checks; the production website and API run on Hostinger.
